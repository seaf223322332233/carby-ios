- Flutter SDK (3.0.0 أو أحدث)
- Dart SDK
- Xcode (لـ iOS)
- Android Studio (لـ Android)

## 🔧 التثبيت

```bash
# تثبيت التبعيات
flutter pub get

# تشغيل التطبيق
flutter run

# بناء iOS
flutter build ios

# بناء Android
flutter build apk
```

## 📦 البناء للـ App Store
